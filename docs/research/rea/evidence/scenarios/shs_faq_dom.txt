    <h2>Generating Documents</h2>
    <dl class="faq">
      <dt>How long does it take to generate a lesson plan?</dt>
      <dd>Most documents are ready in about five minutes ΓÇö including a full assessment package of exam paper, marking scheme and table of specification.</dd>

      <dt>What documents can SHS Planner generate?</dt>
      <dd>Five things: <strong>sample lesson plans</strong>; <strong>assessments</strong> with marking scheme and table of specification; a self-marking <strong>online MCQ quiz</strong>; <strong>schemes of work</strong> for a semester or a full academic year; and <strong>PowerPoint slides</strong> for classroom delivery.</dd>

      <dt>How does the Online Assessment (MCQ quiz) work?</dt>
      <dd>From the Assessment builder, generate a set of multiple-choice questions, then share one link with your class. Each student takes it on their own phone, with their questions shown in a different shuffled order to discourage copying. Results are marked automatically ΓÇö you get a gradebook and a full item-analysis report without marking a single script by hand.</dd>

      <dt>Can I edit the documents after downloading?</dt>
      <dd>Yes. Everything downloads as a standard Word or PowerPoint file, editable in Microsoft Office, Google Docs, WPS Office or any compatible app.</dd>

      <dt>Which subjects and year groups are covered?</dt>
      <dd>A wide range of SHS subjects for Year 1 and Year 2 ΓÇö core subjects, sciences, humanities, business, technical subjects and Ghanaian languages. Coverage is expanding.</dd>

      <dt>Are the generated documents always accurate?</dt>
      <dd><strong>No, and this matters.</strong> Documents are generated by artificial intelligence and are <em>drafts for a professional to review</em>. They can contain mistakes, gaps, or content that does not suit your particular class. Always read a document and correct it before using or submitting it. The tool removes the typing; the teaching judgement stays with you.</dd>

<script>
(function(){
  var KEY = 'shsp_guide_promo_dismissed';
  var popup = document.getElementById('shsp-promo-popup');
  if (!popup) return;

  function alreadyDismissedToday(){
    try {
      var t = localStorage.getItem(KEY);
      return t && (Date.now() - parseInt(t, 10)) < 86400000; // 24h cooldown
    } catch(e){ return false; }
  }

  window.shspDismissPromo = function(){
    popup.style.display = 'none';
    document.body.style.overflow = '';
    try { localStorage.setItem(KEY, String(Date.now())); } catch(e){}
  };

  if (alreadyDismissedToday()) return;

  var shown = false;
  function showPromo(){
    if (shown || alreadyDismissedToday()) return;
    shown = true;
    popup.style.display = 'flex';
    document.body.style.overflow = 'hidden';
  }

  var timer = setTimeout(showPromo, 20000);
  var trigger = document.getElementById('sample-scroll');
  if (trigger){
    window.addEventListener('scroll', function onScroll(){
      var rect = trigger.getBoundingClientRect();
      if (rect.bottom < window.innerHeight * 0.6){
        window.removeEventListener('scroll', onScroll);
        clearTimeout(timer);
        showPromo();
      }
    }, {passive:true});
  }

  popup.addEventListener('click', function(e){
    if (e.target === popup) shspDismissPromo();
  });
})();
</script>

(function(){
  var sid = sessionStorage.getItem('shsp_sid');
  if (!sid) {
    sid = Math.random().toString(36).slice(2) + Date.now().toString(36);
    sessionStorage.setItem('shsp_sid', sid);
  }

  // Page view ΓÇö fire once on load, its own permanent row
  try {
    var vparams = 'event=view&page=' + encodeURIComponent(location.pathname) + '&sid=' + encodeURIComponent(sid);
    fetch('/api/content_click.php?' + vparams, { method: 'GET', credentials: 'same-origin' }).catch(function(){});
  } catch(e){}

  // CTA click ΓÇö any link styled as a call-to-action toward the app
  function trackClick(){
    try {
      var data = 'event=click&page=' + encodeURIComponent(location.pathname) + '&sid=' + encodeURIComponent(sid);
      if (navigator.sendBeacon) {
        navigator.sendBeacon('/api/content_click.php', new Blob([data], {type:'application/x-www-form-urlencoded'}));
      } else {
        fetch('/api/content_click.php', {method:'POST', body:data, headers:{'Content-Type':'application/x-www-form-urlencoded'}, keepalive:true}).catch(function(){});
      }
    } catch(e){}
  }
  document.querySelectorAll('.cta-top, .cta-box a, .promo-cta').forEach(function(el){
    el.addEventListener('click', trackClick);
  });
})();
</script>
