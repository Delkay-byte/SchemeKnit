# School Licensing System

## Overview

TeachFlow uses a school-based licensing model. Each school receives a license that grants access to premium features, teacher seats, and content.

## License Lifecycle

```
Payment Received
→ Payment Record
→ Platform Admin Verifies Payment
→ License Created (status: pending)
→ Activation Code Generated
→ License Activated (status: active)
→ Desktop Activation
→ School Admin Created
→ Teachers Added (within seat limit)
```

## License States

| Status | Description |
|--------|-------------|
| `pending` | License created but not yet activated |
| `active` | License is valid and in use |
| `expired` | License has passed its expiry date |
| `suspended` | License temporarily disabled |
| `cancelled` | License permanently revoked |

## Seat Management

- Each license has a `seat_limit` (number of teacher accounts)
- Active teacher count must not exceed seat limit
- School Admin cannot bypass the limit
- Platform Admin can increase seat allocation
- Platform Administrators do not count as teacher seats

## License Expiry

When a license expires:
- Premium/paid features become unavailable
- Core offline features continue to work
- School data is NOT deleted
- School sees "License expired — Renew to continue premium features"

## License Renewal

```
Existing License
→ Customer Pays
→ Payment Recorded
→ Payment Verified
→ Renewal Created
→ New Expiry Date Set
→ Entitlement Updated
```

Previous license history is preserved.

## Activation Codes

- Format: `TF-SCH-XXXX-XXXX-XXXX`
- Generated by Platform Admin
- One code per activation
- Codes can be revoked before use
- Used codes cannot be revoked
- Codes expire after a configurable period

## Desktop Activation

1. User launches TeachFlow desktop
2. Selects "Activate School License"
3. Enters activation code
4. Desktop contacts central TeachFlow service
5. Service validates code and returns license info
6. Desktop caches license locally for offline use
7. School Admin account is created
8. Teachers are added within seat limits

## Offline Cache

After successful activation:
- License info cached locally in `license_cache` table
- Includes: school, plan, expiry, seat limit, features
- Periodic online validation recommended
- Grace period for offline use is configurable
