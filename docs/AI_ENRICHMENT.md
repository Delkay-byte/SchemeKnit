# TeachFlow AI Enrichment

## Overview

TeachFlow separates **deterministic curriculum processing** from **AI enrichment**. AI is never required — it enhances what the deterministic system produces.

## AI Modes

| Mode | Description | Use Case |
|------|-------------|----------|
| `OFF` | No AI | Default. Fully deterministic. |
| `BASIC` | Suggests activities, examples, differentiation | Quick enhancement without deep integration |
| `ENHANCED` | Full enrichment with validation | Production-quality AI assistance |

## What AI Enriches

AI enrichment adds to lesson plans that are already **structurally complete** from the deterministic pipeline:

| Field | Deterministic | AI Enhancement |
|-------|--------------|----------------|
| `introduction` | Generated from template | Suggest engaging opener |
| `main_activities` | Allocated from scheme | Suggest pedagogical activities |
| `learner_activities` | Generated | Suggest interactive activities |
| `differentiation` | Template-based | Level-specific strategies |
| `assessment` | Template-based | Rubric suggestions |
| `homework` | None | Generate practice problems |
| `essential_questions` | None | Generate open-ended questions |
| `reflection` | None | Generate reflective prompts |

## AI Never Touches

These fields are **never** generated or modified by AI:

- Curriculum data (strand, sub-strand, content standard, indicators)
- Scheme data (subject, class level, week number, dates)
- Calendar data (term dates, holidays, teaching days)
- Teacher data (school name, teacher name)
- Structural metadata (lesson sequence, duration, status)

## Architecture

```
Deterministic Pipeline
  → Complete LessonPlan (100% from data)
  → AI Enrichment (optional)
    → AI Provider (Mock, Gemini, OpenAI, MiniMax, Ollama)
    → Section-level regeneration
    → Content provenance tracking
  → Export
```

## Section-Level Regeneration

Teachers can regenerate individual sections without regenerating the entire lesson plan:

1. Teacher selects a section (e.g., "Differentiation")
2. System sends only that section to the AI provider
3. AI returns enriched content
4. Teacher reviews before accepting
5. Original deterministic content is preserved as fallback

## Content Provenance

Every piece of content tracks its source:

```python
ContentSource.scheme      # From the uploaded document
ContentSource.deterministic  # Generated by deterministic pipeline
ContentSource.ai          # Generated or modified by AI
ContentSource.teacher     # Edited by teacher
ContentSource.template    # From template defaults
ContentSource.default     # System default value
```

## AI Providers

### MockProvider
- Returns placeholder content
- Used for testing and development
- Always available

### GeminiProvider
- Google Gemini API
- Requires API key
- Best for structured prompt generation

### OpenAIProvider
- OpenAI GPT API
- Requires API key
- Most capable for complex generation

### MiniMaxProvider
- MiniMax API
- Requires API key
- Good for African language support

### OllamaProvider
- Local Ollama server
- No API key required
- Works offline, requires local installation

## Prompt Template

```python
ENRICHMENT_PROMPT = """
You are a Ghanaian educator helping create a lesson plan.

Context:
- Subject: {subject}
- Class: {class_level} ({educational_level})
- Week: {week_number}, Topic: {strand} / {sub_strand}
- Content Standard: {content_standard}

Existing lesson plan data:
{existing_data}

Section to enrich: {section_name}

Instructions:
- Use local Ghanaian examples and materials
- No ICT/projector/smartboard references
- Appropriate for {class_level} students
- Follow Ghana Education Service guidelines
- Return enriched content in the same format

Return JSON with enriched section content.
"""
```

## Fallback Behavior

If AI enrichment fails:
1. System logs the error
2. Deterministic content is preserved
3. Teacher is notified
4. Lesson plan can still be exported with deterministic content only

## Safety

- AI content is always reviewed by teacher before final export
- Teacher can reject any AI suggestion
- Original content is never deleted during AI enrichment
- All AI requests are logged for audit
